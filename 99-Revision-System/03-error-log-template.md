## 2. Error types (pick one per entry)

| Code | Meaning |
|---|---|
| C | Concept gap |
| F | Formula forgotten or wrong formula |
| U | Unit or conversion mistake |

| R | Misread the question |

## 3. Weekly review

- Count errors by type. If one type dominates, change the practice method (for example, many U errors means writing units on every line).
- Re-solve every logged question after 3 days, 10 days and 30 days.
- Move any repeated mistake to the "never again" list in the last-week sheet.
